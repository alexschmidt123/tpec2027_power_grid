# IEEE 9-bus A100 online timing measurements

This timing-only experiment loads the final paper's seed-101 Fixed, DAD and RL-sBOED checkpoints; it does not train or replace the information-gain results. All six methods use the paper's original physics and online budgets at T=3,4,5: L=128, 128 planner particles, Myopic 16 proposals x 3 rounds with 32 fantasies, and Step-DAD four refinement updates (batch size 32). The original training archives contain an older 16-update Step-DAD evaluation setting; the timing script explicitly sets four updates to match the final manuscript.

All horizons are measured sequentially on one Grace node with an NVIDIA A100 PCIe 40-GB GPU and Intel Xeon Gold 6248R CPU, using four allocated CPU cores. Each method receives one discarded warm-up history (evaluation seed 91001), followed by the same 32 evaluation systems/noise streams (seed 91002). Online cost is the mean sum of the original evaluator's per-stage decision timers. It includes posterior updates and policy refinement but excludes true-system propagation, observation acquisition, and terminal EIG scoring. These are descriptive timings from one training seed; episode standard deviations are stored in timing.json, not training-seed uncertainty.

Per-horizon manifest.json stores the hardware, checkpoint hashes, settings and source hashes. rollouts.jsonl contains the raw decision timers. The existing offline timing values come from the original A100 training runs, including Fixed initialization in DAD/Step-DAD preparation. IEEE 14-bus online times remain the archived seed-101 A100 measurements over 1536 episodes; different sample sizes and nodes are disclosed in the manuscript.

Run profile_ieee9_a100.py from an A100 allocation with the source/checkpoint archive in --repo. profile_ieee9_a100.slurm documents the allocation used for this measurement. The first job (19926344) was cancelled after detecting the old 16-update setting; its partial data are excluded. The corrected job is 19926361.
